# Daily Dose Studio 🎬

> An autonomous AI video compilation studio that turns raw viral clips into broadcast-quality Daily Dose of Internet style videos with kinetic captions, punchline zooms, and neural voiceover.

---

### Quick Start (Launch Studio)

To launch the web studio on your Mac:

```bash
./.venv/bin/python3 run_studio.py
```

This immediately opens the **Ultra-Minimalist Pure White Studio** in your browser at `http://localhost:8501`.

---

### Run Test Suite (47 Passing Tests)

To verify all 13 built modules:

```bash
./.venv/bin/pytest tests/ -v
```
